# 图标是怎么渲染的

输入是 `WorkspaceDetails.field9`（UTF-8 emoji 字符串）；输出是浏览器 UI 中的工作区图标。

```
field9 存在且能解码为 emoji
    └─ 渲染 emoji 位图（受测样本：黄色文件夹 📁）
field9 不存在
    └─ 渲染 Edge 自带的内置线框图标（叠层矩形），颜色由 field2 决定
```

证据：

- Edge 自己的任务栏图标缓存里同时存在两类文件：
  `<颜色>_dark` 与 `<颜色>_dark_emoji_<workspace-id>_<hash>`。
  前者解出的是蓝色线框叠层矩形，后者解出的是黄色文件夹。
- 同一个工作区在删除 `field9` 并重启后，`scan` 显示 `DEFAULT`，界面工具栏上的图标变为线框。
- 全盘搜索结果显示 emoji 来自 Edge 的图标渲染路径；字体与第三方资源未参与。

因此：

- **Windows 系统字体的角色** 【推断】切换 `field9` 即可改变图标，字体安装与替换操作同图标变更无关。
- **是否使用 Edge 自带资源？** 【事实】回退图标来自 Edge 自带资源；emoji 由 Edge 渲染成位图。
- **新旧图标的差异来源** 【事实】两条渲染分支各自读取不同的资源。

注意 `field2` 只决定线框图标的着色（ARGB），不决定是否使用 emoji；两者是正交的。
