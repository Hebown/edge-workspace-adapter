# 默认（旧版线框）图标能否通过配置恢复

结论：**能，且已实测。** 方式是删除 emoji 字段，让 Edge 走自己的回退分支。

- 旧版图标是什么：叠层矩形线框，Edge 内置资源，颜色由 `WorkspaceDetails.field2` 决定。
- Edge 是否仍保留该资源：【事实】是。任务栏图标缓存中存在该位图，且删除 emoji 字段后
  重新渲染出的就是它。
- 能否通过配置恢复：【事实】能。`details.field9` 缺失即可；不需要替换字体、不需要自绘图标。
- 边界：全量下载会从同步服务器取回 emoji；持久化策略见 `agent.md` 第 2 节。
  此外，新版 UI 可能不提供“取消 emoji”的入口（需求方观察），所以需要一个本地配置工具。

可达状态对比：

| 目标状态 | 写入值 | 实测 |
|---|---|---|
| 默认线框 | 删除 `details.field9` | 【事实】重启后保持，其他字段不变 |
| 指定 emoji | `details.field9 = <UTF-8 emoji>` | 【推断】与既有 emoji 记录的表示法一致；可用 `preview` 检查 |
| 空字符串 | `details.field9 = ""` | 【可测】本机无样本，未验证；不保证回退 |

用户需要的“旧版蓝色线框”就是 Edge 自身的回退图标。
